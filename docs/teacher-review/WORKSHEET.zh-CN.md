# BatchScope 课堂任务单（供老师调整）

**仅虚构模拟数据；不是外部教师制定的正式课程。**

建议用途：数据与质量运营的入门演示。教学时间可先预留 15–20 分钟，这是建议而非测量结果。

## 准备

打开 BatchScope → 生成演示数据 → 截至日期设为 2026-06-30 → 运行分析。保持固定种子样例。回答时写出数字、分母或对应记录，不只写结论。

## 学生任务

1. 总检验数 198、缺失数 14：可判定数是多少？缺失结果能不能当作 0？
2. 超示例范围 74：用于计算此比例的分母是多少？算出比例并解释这是否代表真实药企异常率。
3. 默认工作台显示 32/37：37 表示什么？其余 5 条是否被删除？今天到期是否逾期？
4. 在“偏差已关闭，措施未完成”筛选中找一条措施，打开批次全景。记录批次编号、偏差编号、措施状态。这个组合能直接证明违规吗？
5. 找到六月月度变化：用期初、开启、关闭计算期末。为什么净增加 2 不等于“六月只开启了 2 条偏差”？
6. 比较 2026-06-30 与 2026-07-31：偏差下降、逾期措施增加分别是多少？解释逾期净增加的构成。能据此断言质量变差或 CAPA 有效吗？

## 教师参考答案

1. 184；缺失保留为不可用，不转为零。
2. 分母 184；74/184×100≈40.22%。虚构教学场景，不能代表行业情况；超示例范围标记需要复核，不构成正式调查结论。
3. 37 条未完成措施；默认筛选显示 30 条逾期、1 条今天到期、1 条近期到期；5 条更晚到期仍在完整队列中。今天到期不算逾期。
4. 样例之一：B0012 的关联措施 A0012-1（与 D0012 关联），截至六月未完成且逾期。程序应显示已关闭关联偏差；需要业务上下文，不能自动认定程序违规。可接受其他符合筛选的编号。
5. 20＋5－3＝22。净增加 2 是开启和关闭的合成结果，不是开启数量。
6. 偏差 22→17，净减少 5；逾期 30→33，净增加 3＝4 条进入期末逾期列表－1 条期初逾期措施完成。不能直接证明生产质量、风险或措施有效性。

可补充练习：对比时取消“只看发生变化的记录”，查看持续逾期 29 条。字段和记录以程序实际导出为准。
